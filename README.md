## Event photos

For permanent GitHub Pages event photos, place images here:

assets/events/

Example:

assets/events/event-1.jpg
assets/events/event-2.jpg
assets/events/event-3.jpg
assets/events/event-4.jpg

Then update the event banner entries in index.html.

## Important note about uploading

GitHub Pages is static hosting. The "Select Event Photos" feature previews images in the visitor's browser, but it does NOT permanently upload files to GitHub.

For permanent website gallery photos:
1. Add the images to assets/events/
2. Commit/push them to GitHub
3. Update the event entries in index.html
